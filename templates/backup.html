📲 Cara Pindah Data ke HP / Termux Baru

  1. Klik tombol Download Database Utuh (.db) di atas pada HP lama Anda. File akan tersimpan di folder Download HP.
  2. Kirim file .db tersebut ke HP baru (via WhatsApp, Google Drive, ShareIt, atau kabel USB).
  3. Jalankan server AL-CIVIL di HP baru (./start.sh start) lalu buka browser ke menu ini (Backup & Migrasi Data).
  4. Pilih file .db yang tadi dikirim pada form Impor Data di samping kanan, lalu klik Impor & Pulihkan Database.
  5. Selesai! Seluruh stok barang, riwayat surat jalan, data proyek, dan konfigurasi otomatis berpindah utuh.
